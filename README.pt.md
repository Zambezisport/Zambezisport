# Zambezisport

[English](README.md) | **Português**

🌍 **Saúde ambiental para o desporto ao ar livre — treina forte, lê as condições.**

O stress térmico, a qualidade do ar e a radiação UV decidem se um treino
fortalece um atleta ou o derruba. A Zambezisport transforma dados ambientais em
orientação clara de avançar / adaptar / cancelar para treinos e eventos ao ar
livre — construída para as condições da África Austral, útil em qualquer lugar
onde o clima manda.

- 🌐 **Site** → [zambezisport.com](https://zambezisport.com)

## Código aberto

Pequenos utilitários TypeScript sem dependências em
[**zambezisport-utils**](https://github.com/Zambezisport/zambezisport-utils):

| ficheiro | o que é |
|---|---|
| [`wbgt.ts`](https://github.com/Zambezisport/zambezisport-utils/blob/main/wbgt.ts) | Estimativa de temperatura de globo de bulbo húmido + bandas de risco |
| [`aqi.ts`](https://github.com/Zambezisport/zambezisport-utils/blob/main/aqi.ts) | Índice de qualidade do ar (EPA) a partir de PM2.5 / PM10, com orientação para exercício |

| [`session.ts`](https://github.com/Zambezisport/zambezisport-utils/blob/main/session.ts) | Veredicto composto avançar / cautela / adaptar / cancelar |
